# CFD Codes
This repository contains a collection of CFD codes implemented in C++ and Python. Each code is designed to solve specific type of ODE using various numerical methods. **FVM codes are written in C++** for solving 1D and 2D problems. Additionally, there are Python codes under `legacy/` that were written during my undergraduate CFD course, which include FDM to solve various fluid problems. This repository serves for educational purposes and not optimized for performance or accuracy. The codes are intended to provide a basic understanding of the numerical methods used in CFD and can be used as a starting point for further development and optimization. Each code is well commented, explaining the underlying numerical methods and algorithms used.

Any contributions to improve the code are welcome. Let us create a collaborative environment to collaborate and understand CFD and numerical methods involved. If you have any suggestions or improvements, please feel free to submit a pull request or open an issue.
